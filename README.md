# 🚀 Spring Boot Learning

A production-oriented Spring Boot learning repository covering REST APIs, Spring Security, JWT Authentication, OAuth2, Redis, Docker, Testing, and other backend development concepts.

## 📚 Projects

### 🔐 Spring Security JWT
Production-ready authentication system with:

- JWT Authentication
- Refresh Token Rotation
- Google OAuth2 Login
- Role-Based Access Control (RBAC)
- Redis Token Blacklisting
- Password Reset (OTP)
- Swagger Documentation
- Global Exception Handling
- Validation
- MongoDB
- Docker & Docker Compose
- Unit Testing (JUnit & Mockito)
